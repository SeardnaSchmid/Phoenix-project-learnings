# Phoenix-project-learnings

**Flow Factory**: an interactive 2.5D learning game about the lessons of *The Phoenix Project*,
played on an isometric IT factory floor.

▶ Play: https://seardnaschmid.github.io/Phoenix-project-learnings/

Eight shifts, one idea each: the value stream, the four types of work, making work visible,
Theory of Constraints, WIP limits, technical debt, change & security, and the Three Ways.
Every decision gets an effect check, and the debrief compares your factory with an untouched twin.

Run locally: open `game/index.html` in a browser (no build step, no dependencies).
Every push to `main` deploys the `game/` folder to GitHub Pages.
